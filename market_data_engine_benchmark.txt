Ran benchmark, synthesis. Never ran implementation.
- The RTL design functions as a high-speed streaming IP core. Top-level testbench simulation and verification are executed via Verilator, coupling the 1-cycle latency SystemVerilog filter directly to a high-performance C++ quantitative execution engine over a simulated host interface.
- For real production-grade method, we need to wrap the inputs and outputs into a narrow streaming interface—like an AXI4-Stream bus (e.g., a single 32-bit data bus with a valid, ready, and last handshake). Instead of sending everything in parallel across 394 pins, you serialize the data over a few pins across multiple clock cycles.
